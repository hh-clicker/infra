# Инструкция агенту

## Назначение и границы

Compose-связка PostgreSQL, backend и frontend; Generation Agent имеет отдельный проект.

## Карта кода

- `compose.yaml` — сервисы, сети, health checks, ports, volumes и labels.
- `.env.example` — шаблон конфигурации; `.env` — локальные значения, не для Git.

## Инварианты

- Изменения сервисов, проектов, labels, ports, volumes и health checks согласовывай с launcher и клиентами.
- PostgreSQL доступен внутри сети как postgres:5432 и не публикуется на хосте.
- Backend обращается к Generation Agent через host.docker.internal.
- Обычная остановка сохраняет данные; не добавляй -v к docker compose down.
- Не коммить credentials, реальные env-файлы, дампы и локальные пользовательские пути.
- Dockerfile приложения хранится в репозитории соответствующего компонента.

## Изменения и документация

Изменённый контракт одновременно отражай в клиентах, конфигурации, тестах и документации.
Проверяй утверждения по реализации. Не сохраняй планы, историю обсуждений и результаты
конкретных прогонов в постоянных инструкциях. Действующие причины решений описывай в архитектуре.

## Проверка

```powershell
docker compose config
```

Команды запуска сервисов и живые проверки не являются автономными тестами.
Условия интеграционных и ручных проверок смотри в документации.
